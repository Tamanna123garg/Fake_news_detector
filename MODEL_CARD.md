# Model Card - Fake News Detector (HCLTech Project 31)

## Intended use
Decision support for a **human reviewer** (student project / demo). It highlights wording and writing-style patterns that are statistically associated with misleading content.

**Out of scope / must not be used for:** automatic removal or blocking of content, flagging specific political content without human review, judging individual people or outlets, or any non-English / non-U.S.-political text.

## Models
| Model | Input | Training data | Algorithm |
|---|---|---|---|
| Text model | statement / headline text | LIAR benchmark (Wang, ACL 2017): 10,269 train + 1,284 valid statements | TF-IDF (1-2 grams, 20k features) + Logistic Regression |
| Style model | 4 stylometric features + 2 engineered | `data/dataset.csv`, 5,000 rows | Soft-voting ensemble: Logistic Regression + Random Forest + Gradient Boosting |

Binary mapping for LIAR: REAL = true / mostly-true / half-true; FAKE = barely-true / false / pants-fire.
Explanations: LIME-style local linear surrogates (`src/explain.py`); the notebook uses the official `lime` package.

## Measured performance
**Text model (LIAR test set, 1,283 statements):** accuracy 62.1 %, macro-F1 0.582, ROC-AUC 0.655. Majority-class baseline = 56.7 %.
FAKE class: precision 0.60, recall 0.37 - the model misses most FAKE statements.

**Offline experiment (`notebooks/02_bert_ensemble_lime.ipynb`, Colab GPU, 1,267 test rows):**
TF-IDF 62.1 % -> DistilBERT embeddings + LogReg 63.2 % -> weighted ensemble 64.1 % (macro-F1 0.607). DistilBERT is **not** deployed (needs PyTorch, too heavy for a free host).

**Style model (20 % hold-out of dataset.csv, 1,000 rows):** accuracy 74.2 %, precision 0.724, recall 0.672, F1 0.697, ROC-AUC 0.815; 5-fold CV accuracy 73.3 % +/- 1.1 %. Single prediction ~58 ms.

## Important caveat about the style-model data
Rows 1-500 of `dataset.csv` are the provided sample; **rows 501-5000 are synthetic** (generated by `scripts/generate_synthetic_rows.py` with a deliberately modest stylistic signal). The 74 % figure therefore measures how well the model recovers that synthetic pattern - **not real-world accuracy**. Trained on the 500 original rows alone, 5-fold CV accuracy is 55.4 % +/- 2.0 %, close to chance (majority class = 55.6 %).

## Fairness checks
* Political leaning is **never** a model input.
* Style model, hold-out error rates by `political_lean`: false-positive rate 18.9-21.4 %, flag rate 39.0-43.1 % across Left/Center/Right/Unknown (synthetic labels are independent of lean by construction, so this demonstrates the audit method, not real-world fairness).
* Text model, LIAR test set, by speaker party: flag rate Democrat 21.0 %, Republican 29.7 %, none 26.4 %; false-positive rate 16.7 % / 19.4 % / 16.5 %. Republican statements are flagged more often and falsely flagged slightly more often - a reason this must never be used for automated moderation.

## Limitations
* Low accuracy on real text; many errors both ways. Confidence below 60 % is shown as "UNCERTAIN - NEEDS HUMAN REVIEW".
* Does not verify facts; satire, opinion and sensational-but-true writing can be mis-flagged.
* LIAR is 2007-2016 U.S. political statements; the lexicon sentiment is English-only and simple.
* Style model expects 200-2,000 word articles; shorter text is skipped, out-of-range inputs show a warning.
* Model could be weaponised for censorship; deployers must keep a human in the loop and an appeal route.

## Data licence & privacy
LIAR is provided "as is" for research; original sources retain copyright. No personal data is stored: the web app does not log or persist submitted text.
